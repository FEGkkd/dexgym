- **同动力学基线。** 将之前的 17,000 轮 20 点权重放到同一对齐仿真复评。到 11,000 轮，验证和测试 P95 从 17.31 / 16.52 降到 11.81 / 12.42 mm。验证和测试全部计划帧均获评分，碰撞硬停分别为 0 / 0，检测到穿透的帧分别为 91 / 125。
- **难段与停稳。** 50/50 个定点姿态完成，计分区间到位率为 88.0%，接触 1 帧。连续难段 P95 为 39.54 mm。停稳后的低速度和难姿态的最终位置误差是两个指标。
- **阶段调整。** 从 3,000 轮启用在正常重力与无接触条件下通过筛查的训练集定点示教。6,000 轮检查点之后试验定点几何目标。8,000 轮检查点之后转为常规轨迹与训练集持续腕偏难段混采。从难段池抽取的概率在本快照为 20%，另外保留常规定点重置。
- **对齐检查。** 选定的伺服配置保留正常重力，并使用 16 ms 位置目标滤波。在两组初始姿态和 150 个控制拍的一致性检查中，CPU MuJoCo 与 GPU Warp 的最大臂角差为 0.00034°。该检查覆盖规定的仿真输入和控制器配置。
