# Actor observation noise contract

`ObservationNoiseSpec` declares distribution (`disabled`, `uniform`, `gaussian`), observation schema, one scale and unit per feature, and version `actor_observation_noise_v1`. Uniform scales are half-widths in the declared feature units; Gaussian scales are standard deviations. `ObservationNoiseModel` owns an independent seeded Torch generator per device. Training draws are reproducible from its saved generator state. Evaluation is deterministic by default and can explicitly request noisy sensing.

The order is: real or predicted **physical state** → Task `observation()` → noise → Actor history → Actor. Replay stores that actual Actor history. World Model state and next-state labels, FK, Reward, Hard/Soft Termination and Critic features always use clean physical state. Imagination samples the same task noise contract after computing each predicted physical next state and its reward/termination. Noise is independent of the Action Gradient, so BPTT remains differentiable. RunningNorm updates once per new real training observation, not for every old history frame or sampled validation window.

Task JSON can set `task.observation_noise` with `distribution`, `observation_schema`, `scale` and `units`. The dimension and schema must match `TaskSpec` exactly. The archived `reach_noise_config.json` is an executed example for Reach's 48D observation (`14 normalized q`, `14 normalized qd`, `14 normalized command`, `6 TCP error metres`). The Core Newton collector rejects native environment observation noise settings, which would otherwise produce a second or ignored noise path. Existing Checkpoints with no noise field retain the disabled behavior and original Actor output.

The checkpoint manifest binds the noise spec to the Actor and saves the generator state for exact Toy full resume. Newton fresh-physics resume starts a new physical Episode; it does not claim bitwise continuation. The independent evaluator can use `--noisy-observation` only when the saved Actor has a noise spec.
