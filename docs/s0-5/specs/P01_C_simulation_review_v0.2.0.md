# P01-C 审查修订实施规格 v0.2.0

使用 P01 v0.2.1 的源谱系、预算与域，新增 [DCR-002](../dcr/DCR-002_simulation_and_real_clock_qualification.md) 用途和分门。原 [实施规格](P01_C_calibration_and_causal_sync.md)、原 C1/C2 及 attempt-03 不变。

- 固定同七个原始开发母源、同 23 个 realtime 索引窗口和每窗 100 个 20 ms 名义拍。按冻结的窗口和 ordinal 配对。只用 UTC/realtime 找原记录与锚点，事件、到达、cutoff 与 tick 全部在 collector 单调域。窗口起点通过已记录的窗口前双时钟锚点平移，单位斜率。锚点差和窗口内残差分别报告。选择锚点不使用窗口开始后的样本。缺独立真实时钟域前保持 C2-RT BLOCKED。
- 可信流的新失效、来源不完整证据、时间不可用与时钟重置必须撤销旧输入。过时身份包和旧映射世代可丢弃。当前世代安全流按可见时刻处理，异步 UNSAFE 或未知许可触发 latch。可用安全状态加新鲜输入后才能恢复。安全事件同拍先于 pose，解除时间与重新采样时间均须严格满足。安全许可为数据消费门。
- 重启、时钟或标定与拓扑切换清除相应历史。对同到达使用稳定排序键，低序号的安全更新在同实例中先处理；多条不同流分组按安全优先。先确认身份和映射世代，再认定时钟回退。
- pose、速度、许可分别输出。速度采用同连续段先前采样的后向差分，采样年龄、长间断、未知时间差各自显式失效。HELD 仅持有尚有效的上次差分，加独立年龄及代理/模拟标签。MANUS 窗首缺前驱时保守为 freshness unknown，只有连续 writer 观测证明源身份变化才进入仿真 pose 缓存。
- 在历史窗口重读原包及配置 SHA、固定轨迹和阈值，以 60 ms age、35 ms skew、100 ms safety stale、60 ms 插值 gap、8 ms 模拟到达作为原有诊断参数。保留从旧产物还原的 2,248/2,300 基线。报告四流联合条件和每个诊断流单独分母，匹配真实窗口近安全事件的旧/新 mask、年龄与速度，离线 bracket span、原始采样 skew、每侧点位与 fingertip、腕位移/旋转、双腕相对及双手局部形状。各分组分别计量，不构造世界系机器人指尖。
- 反例测试必须先在旧代码运行，再跑新代码。数学锚点测试只证明估计算法。真实 regression 复验原始消息，并验证未来变异、删除、前缀和批/流结果。推荐门逐项列 C1-GEO、C2-SIM、C2-RT 和物理注册。只有实际技术通过才提交 READY_FOR_REVIEW，P01-D 启动再单独批准。
