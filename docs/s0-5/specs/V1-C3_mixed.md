# S0-5 v2.0.0 V1-C3 混合训练与有界优化

状态 DRAFT_READY_FOR_REVIEW，技术门 G-C3。由 WM & Training Agent 和 Main Agent 执行，Independent Reviewer 核验候选、预算、真实物理结果及范围。前置 G-C2 与 G-C0 技术通过，整体授权与剩余额度有效。

## 目标和范围

维持静态和动态，加入困难采样、合法初态变化和有限仿真扰动，形成可被独立评估的 checkpoint。

## 输入与前置

读取 C2 checkpoint、原 RMB、锁定配置、C1/C2 回归及全量台账。上一阶段技术门和当前 WM 有效性均须交叉验证。

## 架构和实施

维持静态和动态，有限增加困难采样、合法初态变化和仿真扰动，输出可到 V1-D 独立评估的 checkpoint，保留每个失败和已证实的物理适用域。候选训练分配 25% 静态、40% 原速动态、20% 冻结困难、15% 轻量仿真扰动。输入为 C2 checkpoint、原 RMB、锁定仿真配置、C1/C2 回归和上一阶段完整台账。轻量候选一次一因子：仿真臂滤波 τ 在确认后 0.9–1.1 倍基准，初态关节偏差在残差尺度的 ≤0.25，接触几何与硬限制保持不变。每种扰动公开 seed、注入时点、状态、是否反弹和是否在部署可见。新增 profile 需 CPU/Warp 对齐、目标与安全接线验证并按域重验 WM。V1 轻量扰动只反映仿真，完整鲁棒性和真实系统辨识属于后续。

建议执行次序为冻结混合比例、固定比较、筛查 C2 遗忘、观察 WM 和实际失败、按权限调整一组因素再在同一真实比较上重验。

## 数学与量化

最大十指误差、止稳 RMS、真实控制失败、动作饱和和约束介入，加上幂等的资源预算日志共同决定诊断。扰动评估和名义评估各自持有来源及分母。恢复时间在已知扰动结束后的实际控制拍起算，首次达到并连续 5 拍保持规定带宽为恢复，未恢复为删失。

## 单元和集成测试

- 单元测试采样比例、互斥标签、预算整数累加、重试计费、回归样本时间、扰动只在指定拍生效。控制脚本用合成坏状态验证拒绝安全越权、用过期 WM 发 Actor 更新、覆盖失败和替换已冻结评分。
- 集成以同初态、目标、时钟、profile 运行真实 B0/B54；对 C1/C2 固定组验证误差、完成率、动作饱和、约束事件和模型—实际差。每种候选轻量扰动至少 128 个配对窗口且覆盖不少于 4 个验证母源，名义完整固定集与扰动报告分列，源与时距隔离继续保持。
## 实际运行和自主变体

仅在 [参数登记](V2_parameter_registry_training.md) 范围内优化，每阶段 ≤2 项学习变体、≤2 次验证重跑。改动先登记 source SHA、假设、目标、拟修改量、影响 gate、预算和 rollback，再执行。目标、分母、split、技术门、硬安全权威和资源上限锁定。以实际闭环为 checkpoint 比较依据，独立保留 reward/horizon 不同的 imagined 曲线。

## G-C3 技术验收

G-C3 要求实际配对结果完整分母，至少一个可复验的 checkpoint 通过安全、因果、功能和适用域的 WM 检查，关键独立发现均已关闭，并保留 C1/C2 遗忘和全部失败结论。以冻结 V1 性能候选为优化目标。性能门达不到时封存低资格潜在候选，由 D 独立裁定导出和部署等级。

## 预算、失败与风险

C3 混合训练、优化及失败重试合计≤10M 真实训练 transition。每次独立真实验证计入评估预算。硬违规、因果破坏、活跃 WM 失格、持续模型利用、无可恢复 checkpoint 或预算用尽时停下受影响任务并登记。未证扰动、跨场景遗忘、模型适用域漂移须逐条分析。
