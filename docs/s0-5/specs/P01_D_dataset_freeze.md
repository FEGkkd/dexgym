# P01-D 数据资格、QC、划分与构建预检 v0.1.0

继承已批准 [P01 v0.2.1](P01-data-v0.2.1.md)、DCR-001/002 和 [P01-C 最终补丁](../reports/P01_C_final_patch.md)。冻结候选待人工签核。仅开发 HMB，C2-RT、基座注册、P01-T、Final Test 独立 BLOCKED。

## 资格与预注册样本

固定对 A1 32 个原生真人母源逐一按母源登记。七个已有证据与 25 个待逐源复验使用同一严格入口。89 个来源未知、已证实仿真回放、EgoPro、重复和衍生输入禁止进入白名单。记录 ID、母源、原始文件 SHA、实际 MCAP 内嵌 schema、同时见证的 writer/collector、采集期校准、原 topology、双腕配对、safety/validity 和可用时钟。旧 HMB 未审来源必须独立重新检查并实际解码。出现来源、校准、时钟或字段缺证，保留原因并隔离。已知 unsafe 和设备掉帧保持为明示观测，禁止删除困难但合法运动。

[样本计划](../evidence/P01_D/sample_plan.json) 锁定窗口，使用 recorder realtime 只定位物理原包。在可选录制中取首、中、尾各 1.2 秒，首/尾偏置 0.45 秒，前后 0.25 秒上下文。短源（不足三窗互斥长度）改用一个居中窗，低于 2 秒无充分试验资格。按录制 ID 固定顺序；不看姿态和结果选窗。分析共享 collector monotonic 模拟网格，显式 50 Hz 及 8 ms 模拟到达。时间重置、源漂移、缺锚点和未知语义单列，实际 VERIFIED 继续为零。

## QC、split 和覆盖

源资格硬门包括采集期源/哈希和实际 schema，对照固定消息绑定，25 节点仅为当前观察，拓扑按真实 ID/父图验证。原始四元数需有限且可单位化。两侧各需至少 20 对同原戳腕配对，软件重建每侧位置和角度上界沿用 1e-5 m 与 rad，实际物理基座另验。对已知捕获时代、拓扑或标定版本变化建立分段。用 host 双时钟对残差上限 1 ms 标记不可建窗口。源时钟相对已观测轨迹回退、generation 变化、失锁、不可证明的边界构成硬隔离，不猜估计。源资格与阈值选择分离。没有有效数据或仍不具基础资格的源保持待核查。

split 基于原始母源，SHA-256(seed 与母源 ID) 确定顺序，同根不可跨集。目标约 25% Validation；以可证任务、日期、采集配置作分层控制，优先保证 Train 覆盖及 Validation 的多样性，再视稀疏情况填充。session 未证，显式标记。历史用途按原登记的母源记录保留，缺条目是 UNKNOWN；重复测试仅标开发。Final Test 不分配任何现有母源。split 算法及种子固定在查看候选参数结果前。

参数轴见样本计划，各轴相对固定 C 诊断组跑单因素，小组结果逐源、侧、流、运动类别记录。按 Train 逐轴，从严格到宽松选最小候选，须保留相对同轴宽松组整体覆盖 ≥97%、动态覆盖 ≥98% 且每个有计数的任务 ≥90%。再以 Train 检验联合候选；若组合未保留相对参考的覆盖目标，回到固定诊断组并如实列示。超过参考组的宽松选项仅作敏感性见证，不能自动放宽。Validation 只出冻结候选的描述结果。参考离线速度大于 0.02 m/s 作窗口动态标签，含有可靠样本差的左右手、腕和双手同时运动才计覆盖，连续静动改变按连续三拍定义。动态、静态、停止和每一路各自分母保留。

四元数范数误差报告原始流，数值容差按实际最大偏差向上取十进位，至少 1e-6，并限制 1e-4；超上限隔离版本，不修复物理姿态。骨长按同拓扑/侧/父边的离散差与动态速度分开，Train 的分位和按窗上界生成异常审阅标记，保留高速和真实困难状态，不用速度、骨长或预期 IK 误差裁剪数据。C2 速度资格独立。连续有效段固定生产最短候选五拍（100 ms，保留五帧控制历史进入条件），并报告三、五、十拍敏感性。失效、UNSAFE、UNSYNC、不可跨越的屏障、时钟/拓扑/标定版本切换和孔洞切段，不用补帧拼接。分区边界不跨越。对于少样本运动，报告覆盖局限。

空间指标在窗口中分别对 SDK 原始 TIP、掌系、双腕、腕间 SE(3) 以及左、右和腕手 skew 计量。参考离线是诊断插值。禁止解释为世界系机器人十指或实物精度。时间、覆盖、重复率与丢失、无效原因各列分母。估计全录制时长/帧数仅以有限窗口外推，P01-E 用实测值替换。

## 生产契约、预算和退出

版本化 HMB 数组以 [C 最终补丁报告](../reports/P01_C_final_patch.md) 交接字段为最低要求。独立 causal/offline 分区、稳定 shape/dtype/单位和缺测掩码，保留原始端点、同一物理索引字典与校准、拓扑、时钟审计表。全量入口不得接受旧 NPZ 或历史诊断产物，绑定最终同步器的源文件 SHA 和同步基线 commit。causal 输入限制可用前缀，离线是明确用途的另一产物。只输出历史仿真等级，拒绝 VERIFIED 宣称。

仅生成有界试片。测 MCAP 枚举/读取、CDR 实解、同步吞吐和峰值 RSS，记录占用、临时文件、写放大。用同试片验证单工/双工一致及故障不发布、重复运行可恢复。预算用保守结构上界、原始总秒数与实际试片足迹共同估算，保留至少 20 GB 磁盘与 8 GB 可用内存，暂停超界。输出为新目录下 staging，经哈希校验、fsync 后原子发布。失败记录保留，禁止移除用户数据。
