# S0-5 v2.1 RMB、评分和门禁修订提案

**DCR-009 · `PENDING_HUMAN_REVIEW`。** 本文拟修订 V1-A、RMB、Reward 接口和评价协议。已经签署的 v2.0.1 契约、M0/M1 和当前 Campaign 证据主张以现有登记为准。本文的样例字段与阈值是下一阶段设计输入。[DCR-009](../dcr/DCR-009_home_anchored_human_intent.md)

## 1. 数据家族与不可变身份

为 `START_HOME_ANCHORED_V1` 单独建立候选家族，家族身份绑定 HMB E1、原计划、P02 目标、代码与模型资产、物理标定、锚点规则、坐标定义、Servo/安全参数及授权回执。其目录和运行 ID 独立于 P02、DCR-008 和 v2.0.1 名义银行。原始 HMB、P02 数据、M0、M1、既有实验与失败逐字节保留。历史目标可按原生成版本和源拍引用，也可在独立候选数组中精确复制。引用应能取回完整目标、有效位、构造版本和原评价回执。

| 数据层 | 来源、定义和使用范围 |
| --- | --- |
| `RAW_HUMAN_GEOMETRY` / `CALIBRATED_HUMAN_GEOMETRY` | 原始 MANUS 局部地标、原 Tracker 姿态和必要的物理标定适配。标记器原点、解剖腕根、掌与机器人 TCP 以不同 ID 保存。保留录包、时钟和校准不确定性。 |
| `M0_TARGET`, `M1_TARGET`, `START_TARGET` | 三个独立人体意图版本。DCR-009 提请把 `START_TARGET` 作为未来版本化主评分及 Reward 目标。每个目标自己的有效性和源身份可复算，M0/M1 继续可用作并列审计和匹配对照。拟修订正式目标须取得人工批准并重新冻结。 |
| `ROBOT_MORPHOLOGY_TARGET` / `FEASIBLE_GEOMETRY` | 可选的、另行版本化的人体局部骨长适配和独立可行见证。保存形态适配差、路径及残差约束证明和 UNKNOWN。形态目标本身不授予可达性，有限搜索空结果只授予 UNKNOWN。 |
| `Q_NOMINAL` | 同一准入版本的策略无关缓存名义动作，固定 `CACHED_CAUSAL_NOMINAL_REFERENCE` 身份。按控制周期记录因果输入、连续 SDK 状态、Cartesian 请求阶段、原始 SDK 输出、命令接纳、名义 FK 和失效原因。实际部署使用实时 `q_nominal_online` 家族，两条运行路径需要同输入同状态及实际录包配对。 |
| `Q_ISSUED`、`Q_APPLIED` 与 `Q_MEASURED` | 同一仿真实例的有名下发命令、驱动可证明接受或生效的输入、实测反馈。发布、驱动接收及应用、反馈时刻分别保存。缺少 ACK 或生效观测时，`Q_APPLIED` 记 `UNKNOWN`。无 Policy 的实验中，名义输出和已下发值可在具备证据的组别、周期和世代相等，两列仍保留各自身份。 |

人工批准之前，任何 `START_TARGET` 或缓存候选均无 Gate 或训练资格。`Q_NOMINAL`、`Q_ISSUED`、`Q_MEASURED`、Servo 反馈、SDK FK 和 Oracle 不参与生成独立人体目标。Robot Home 的真实反馈只参与有资格的初始锚定与过渡起点验证。目标生成后，期内人体几何从源和锁存矩阵复算。

## 2. 拟议存储和复现字段

保留现有 20 ms 因果控制格和 54 轴有名顺序。逐拍整数用 `<i8` 时戳和 `<i4` 分区或世代索引。目标、命令与反馈承载使用 `<f4`，独立标定、SE(3) 复算、门槛见证和证据收据使用 `<f8`。四元数固定 XYZW，位移 m，关节与 SO(3) rad，速度 m/s 或 rad/s。有效位为 `bool`。任何未资格数据保留列占位和原因码，评分以资格位为准，不能根据有限占位值推定样本可用。

| 作用域 | 拟议字段与形状 |
| --- | --- |
| 源与截止 | 母源 ID、分区 ID、原 `plan_ordinal`、`tick_ns`、`cutoff_ns`、`source_indices[4]`、`capture_bounds_ns[4,2]`、`receive_bounds_ns[4,2]`、`sample_age_ns[4]`、时钟和源发代、标定/拓扑世代、原联合有效位及安全许可位。 |
| 独立 START manifest | 每个 `(root,generation)` 一份。源指针和原显式 START 事件身份或 `RECONSTRUCTED_START`，稳定窗首尾和终止截止、逐路有效性及速度支持，签名 `home_q[54]` 和实测 Home 及双腕/掌姿位，人体 START 对应姿位、间距和中点，`R_cal`/`C_L`/`C_R` 证据 SHA，`T_k[4,4]`，初态可达证据、过渡包、失败或 UNKNOWN 与不确定性。保留没有合格 manifest 的原定 root/generation 并标记 `START_UNQUALIFIED`。 |
| 每个独立几何层 | `wrist_xyz[2,3]`、`wrist_xyzw[2,4]`、`palm_pose[2,7]`、`world_tip_xyz[2,5,3]`、`local_landmark_xyz[2,5,4,3]`、`pinch_local_xyz[2,4,3]`、`cross_world_xyz[5,5,3]`、`relative_wrist_[xyz,xyzw]`、同点坐标身份及各字段独立掩码。原 M0/M1 缺少的字段按照原审计适用范围标记。 |
| 指令与执行 | `q_nominal[54]`、`qd_nominal[54]`、`raw_ik_arm[2,7]`、`raw_sdk_hand[2,20]`、生成目标各阶段变换，`q_issued[54]`、可证实的 `q_applied[54]` 及各组 ACK/生效时刻、`q_measured[54]`、`qd_measured[54]`、Servo 暴露状态、命令序列/会话/有效截止、命令因果联结、反馈到达及年龄、状态与 `held`、关节与组有效位。未暴露 Servo 状态或 SDK 内部输出记录 `UNKNOWN` 和替代取证计划。 |
| 审计和复算 | 真值来源、独立 FK、对应域、候选方案原始失效、安全拒绝、不可达证明或 UNKNOWN、独立改善见证。每份运行保留原始日志、输入/输出摘要、代码及资产 SHA、审查人、失败和重试。 |

生成顺序以 root 与原生产时序为主。普通分区边界只改变块地址，不重置原生会话。明确的 START 重启、时钟/标定或不连续拓扑变化、需要正式重置的失效或安全复位产生证据化新世代。不得用后续成功的 START 追溯清除原失败、空窗或旧状态。未来 Reader 可为回放和连续性审计重建相邻分区的前缀，并在真正的世代边界清除历史。计入 70% 门的成员继续由原签名 `(partition,end_tick)` 候选窗决定。跨分区连续性只另作诊断计数，改用其他历史成员定义需重新批准。

## 3. 计分、Reward 和历史覆盖

**冻结覆盖合同。** 提案保留两个 split 各自的原始分母与阈值。原来的精确/合法参考指标和提议的新主动指标并列留存。新的分子、匹配时间与独立安全接纳规则均需人工批准后生效。

| 范围 | Train | Validation | 总计 |
| --- | ---: | ---: | ---: |
| 母源 / 分区 | 24 / 228 | 8 / 80 | 32 / 308 |
| 计划拍 | 86,338 | 30,275 | 116,613 |
| HMB 联合有效拍 | 85,382 | 29,150 | 114,532 |
| 原 HMB 五帧候选 | 82,559 | 28,237 | 110,796 |
| 85% 名义覆盖最少合格拍 | 72,575 | 24,778 | 分别判定 |
| 70% 因果五帧覆盖最少合格拍 | 57,792 | 19,766 | 分别判定 |

新主动分子候选要求原联合有效拍、已通过该世代 START、当前输入合法且按两侧会话与截止配对、54 轴分组命令具备明确接纳语义、签名独立关节／耦合／步长／扫掠路径及碰撞检验、当前目标确有跟踪证据且所需反馈新鲜。可计入有独立资格的正常、受限主动或已达当前静态目标的稳态；在未达目标时维持上一命令记 HOLD。命令发布、START 成功、仅 SDK 返回、投影到不合格阶段、`HOLD`、`FALLBACK`、`FAILED`、`UNKNOWN`、失效跟踪与缺测都不能顶替有效主动跟踪。可达性有证据时独立记录，证据不能直接替代主动跟踪判定。

五帧分子要求在原签名候选身份内，连续五个原计划拍都满足冻结的输入与实际跟随资格并属于同一连续世代，时间单调且没有未来样本、丢失、补帧或测量时间逆转。原分区边界不可伪造重置，真正的 START、过渡、复位、失效间隙或进出不合法 HOLD 需截断。启动前及 START 过渡拍仍计入原分母但不计入历史分子。任何改变原 eligibility 或 denominator 的提议都需另行登记并批准。

`START_TARGET` 的任务误差在同一时刻和同一参考帧预登记。世界指尖与位置为逐点欧氏量，腕姿态为 `angle(R_targetᵀ R_actual)`。局部地标和同手捏合只在对应有名掌系评价，跨手指尖向量与双腕相对变换在声明的共同帧评价。相对姿态误差通过旋转合成后的 SO(3) 对数／角度得到。速度使用同世代原始可用点和因果后向差分。保留原最差指、静态/动态、尾误差、计划域、失败复合指标和 P50/P95/P99 统计规则。Reward 继承原各项定义和权重治理，拟变的是经批准的独立目标来源与域资格。安全裁决和终止权保持独立。Actor 不读取轨迹 ID、未来目标、Oracle 或审计诊断。

适用版本改变后，原 M1 和新 START 的结果按目标和支持域并列报告。每个分位数、有效覆盖、失败和 UNKNOWN 都带分母，保留静态与原速动态分层、每根与各 split。原 B0/B54、低误差域、共同可改善域、Servo、World Model 和部署相等性不能继承；拟用新版本须重办相应独立资格。P02 历史静态用途、旧 M1 原评分以及正式 Final Test 和真机门禁以原回执管理。

## 4. 执行顺序与后续验收

阶段一交付本提案、源及历史证据审计、独立评审和合成设计检查。用户明确批准 DCR 后才进入实施与只在 Train 上的有界参数定标。六个不同 Train 母源按预登记的掌心方向、腕间距和动作类型分层入选；样本身份、选择规则、负控所用样本及重试上限事前登记。保留难例与未资格母源，禁用 Validation 拟合和挑战阈值回调。先核验坐标和 Home／过渡的独立证据，再进行原生 MuJoCo 回放、全层 54 轴审计和独立审查。提交 Pilot 的完整清单和失败帐后等待人工 Pilot 批准。

正式全量只接受同一已批准 DCR、合格物理标定、签名模型／仿真模型一致性或已批准桥接、六 Train Pilot 合格、目标与 Reward 冻结、85% 和 70% 口径冻结、独立 Reviewer 同意以及新的用户全量授权。随后每个有资格的世代依次执行 Home、锚点和固定映射、过渡、原始时间轴回放，再独立复核。全量 32 根结果即使生成完整，仍须独立审计并提交人工审核。监督者不得从上一轮诊断或 Campaign 授权推断这些新批准。
