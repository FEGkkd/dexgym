## 1. 分批执行与共享证据

采集计划至少预登记 FIT 拟合批、REPEAT 同工位复测批、HOLDOUT 独立采集批。以完整 source_lineage_id 和预分配 UUID 分配，优先按独立日期或拆装前后隔离。现场勘查后锁定样本数。manifest 在查看性能前固定并公布 SHA。重新上电按新 boot 和时钟世代记账，可仍属同一系统辨识分组。每批校准位姿、锚点和激励的拟合与留出也须分离。重做使用独立 Run ID，定义原证据失效范围。硬件保留批仅用于测量资格，项目 Final Test 保持独立的母源和访问日志封存。[历史用途与 Final Test](../HISTORICAL_DATA_USAGE.md)

## 2. 物理 robot-base 注册及 TCP、掌和参考点

| 标识 | 定义及见证 |
|---|---|
| \(O,M\) | \(O\) 为当次 OpenVR/Tracker 公共追踪世界，\(M\) 为独立测量设备参考坐标。记录追踪空间重置、光学基准稳定性及重定位。 |
| \(B_L,B_R\) | 左右机械基座坐标，采用现场机械图纸给出的原点和正轴。分别以独立量具测量基座刚体治具，保留平台平面、底架和两臂安装位置与姿态。 |
| \(F_s,T_s,P_s\) | 同侧机械法兰、驱动语义的实际 TCP、掌部刚体。通过认证治具、工具端独立枢轴和姿态测量确定 \(T_{F_sT_s}\)、\(T_{T_sP_s}\)。登记适配器、手型、负载和 TCP 定义。 |
| \(Q_k\) | 共同参考目标、可测功能指尖标志点或安全界标。保存带 ID 的局部位置、测量不确定度及可见性。若标志点不在接触位置，单列其与实际接触点的偏置证据。 |

\(T_{AB}\) 将 B 中的点变换到 A。选定覆盖工作空间且可见的独立固定靶标，预登记拟合位置和留出姿态。采用非共线的刚体基准与非共面的空间验证位置，报告几何条件、尺度及姿态覆盖。用外部校准量具分别拟合 \(T_{MB_s}\) 和 \(T_{MO}\)，组合 \(T_{B_sO}=T_{MB_s}^{-1}T_{MO}\)，通过同一 \(M\) 检验左右基座闭环。分别复验 \(T_{MT_s}=T_{MF_s}T_{F_sT_s}\) 和 \(T_{MP_s}=T_{MT_s}T_{T_sP_s}\)，以独立实测点作参考。基座、腕、掌和功能指尖的误差分别报告。保存遮挡、重复装夹、跟踪重定位和工具配置的影响。P02 现有软件映射作为历史仿真对照保留。

记录旋转正交性和右手性、逆变换闭环、左右轴识别、拟合设计矩阵条件及留出点三轴有符号残差。分侧、分日和拆装前后报告平移毫米、SO(3) 测地角、覆盖和失败。给出测量区域中的位置不确定度，包含设备校准、治具、配对、刚体拟合、重复和装拆。杠杆臂上界 \(r\) 与角不确定度 \(\delta\theta\) 对位置的上界为 \(2r\sin(\delta\theta/2)\)。相关项保守合成，有已知协方差时使用其传播，区分概率区间和保守界。测量负责人和独立审阅在读取留出批前锁定仪器、空间范围、各项不确定度份额及接受阈值。

**工作空间对照。** 冻结原始母源与 tick、M0/M1 目标和全量分母，冻结测量签核包络 \(C\) 及有合格外测覆盖见证的格集 \(V\)。格集按臂侧、地标、方向、配置与会话登记，孔隙保持未覆盖。以对应机械基座将历史仿真目标从其模型基座坐标送入共同外测坐标 \(M\)，核对两侧坐标闭环并传播基座、地标与仪器的不确定度，得到每个目标的保守集合 \(U\)。若 \(U\subset C\cap V\) 则为 OBSERVED_COVERAGE，若 \(U\subset C\) 且 \(U\cap V=\varnothing\) 则为 OUTSIDE_OBSERVED，若 \(U\cap C=\varnothing\) 则为 OUT_OF_CERTIFIED_RANGE。缺可比签核、基座闭环失败、边界相交、地标或遮挡证据欠缺归 UNKNOWN。按同一目标行输出 M0/M1 的分类、各自边界距离及不确定度、同分母变化和失败来源。包络仅适用于签核的工位、装配及运动条件，历史目标、注册参数及评分权重保持冻结。

## 3. C2-RT 事件、配对锚点和时间误差界

每个时钟标记 domain_id、device_alias、boot_id、clock_generation、raw_value_int、units_or_tick_period、rollover、clock_policy、sync_lock。转换层另记映射版本及所有 anchor UID。以经校准的独立参考 R 为共同轴，对设备或应用 D 的每个世代验证仿射或分段映射 \(R=\alpha D+\beta\)。一对 anchor 绑定同一物理事件的 device_event_uid、reference_event_uid、两域原始上下界和独立仪器波形或图像。设备支持时使用独立可观测触发。无设备触发时，使用可识别的外部光学事件及曝光窗口，测得能被独立观测的区间。量化同步时钟、触发链和事件识别的不同误差，包括曝光、取样窗、量化、抖动、漂移和留出残差。

锚点约束 \(\alpha,\beta\) 的集合，映射的上下界为该集合对原始时间戳区间的最小/最大值再加独立仪器和漂移包络。用另留锚点复核，线上资格仅使用该拍已可用的前缀锚点。离线全段估计另存 DIAGNOSTIC。同步失锁、未知时基、换代无桥接、包络欠定和缺留出见证均标记 UNKNOWN 或 UNUSABLE。可界定外部事件到输出的段单独登记，内部物理采样、接收或驱动应用的缺失继续为 UNKNOWN。时延区间为 \([Y^- - X^+,Y^+-X^-]\)，分开记录负区间和零交界。不同设备原始时间戳先有有证的公共映射再比较。

| 事件 | 记录位置及必需字段 |
|---|---|
| 人端传感器捕获 | MANUS 左右设备身份、采样 UID、packed source 原值及 SDK 解压版本、SDK receive 域。Tracker 左右设备身份、原生计数/时间或可证曝光界，原始和注册副本共用稳定源 UID。区分 recorder 采样选择和物理传感器事件。 |
| 控制器接收及可用 | callback 入口读单调原值，另记锁争用后的缓存提交。保存实际被快照采纳的四路 UID、缓存可见时间及世代。重定向手和臂控制循环分别记录。 |
| tick 与 cutoff | 记录实际 tick_id、定时器启动、读快照的 tick 参考时刻及冻结输入的截止、各路年龄和失效原因。对实际采用的 UID 检查 \(capture^+\le tick^-\)、\(arrival^+\le cutoff^-\)，缓存提交也须在截止前可见。晚到、缺失和 HOLD 独立记账。 |
| 下发、应用和反馈 | 记录 post-safety issue 调用前后、驱动接收及准入、设备应答语义、可证设定应用、反馈物理取样、驱动及控制器接收。各时钟独立登记，命令关联见第 4 节。 |
| 共同锚点和监控 | 保存触发、独立仪器原始时间及对照通道、软件观察器、两侧时钟质量、CPU 队列和环路耗时。设备、时钟和追踪重置时增加世代，保留原始故障。 |

分别报告四路 offered/present/accepted/used/verified、重复、乱序、缺失、晚到、停顿及负时延。分环节记录采样至接收、可用至 tick、tick 至 issue、issue 至应用及反馈的置信区间、分位数和失败。根据最小可用周期、捕获同步目标、采样率和仪器校准，提前冻结最大时间包络宽度、世代有效期、覆盖门和判据。真实有效片段与不足片段分开报告。

## 4. P01-T 命令链、轴级证据及动态覆盖

| 记录 | 合同 |
|---|---|
| 设备和轴定义 | 两臂各 7 轴、两手各 20 轴，由独立 fixture、设备身份及 SDK 映射验证。保存 logical_axis、ros_joint_name、sdk_axis_or_nid、sign、zero、native_units、conversion_id。位置、速度归一为 rad 和 rad/s。实测电流 A、力矩 N·m 仅在单位和物理语义有证时归一，保留原值、掩码、校准、增益及模式。 |
| 请求与发布 | request_uid=(run,controller_boot,generation,tick_id,group,subrequest)。保留不获准请求及原因。issue_uid=(run,publisher_instance,source,session_or_generation,group,sequence) 可缺失。实际发布引用 request_uid，记录 q_requested、q_issued、最终裁剪、持有和调用结果。手与臂的序列分域。 |
| 驱动及应用 | 逐层保留 receive_uid、driver_decision_uid、sdk_submission_uid、device_ack_uid 及上游关联和状态。设备应答须明确表示接收、队列或已应用。SDK 返回单列。无设备读回时保留 UNKNOWN 或有证的 APPLIED_ESTIMATE，禁止产生伪实测 q_applied。 |
| 反馈与外测 | sample_uid=(device_alias,channel,boot,epoch,source_sequence,raw_capture)，附分片和原始偏移。控制节点接收另记。若可用则记录实际 q、速度、每轴质量、饱和、丢失、安全，以及设备或外部物理参照。FK 和差分作为派生量记录。 |

每个环节以唯一稳定 UID 连接，保留连接方向、基数和时序。相同 payload 的重复样本归原始 UID 并保留传输序号。同 UID 的内容冲突须隔离。有效反馈允许多于一个、丢包或窗口重叠。没有必要应用关联、独立响应证据或时钟界时保留 UNPAIRED 或 UNKNOWN，纳入缺失统计。近邻时戳仅作候选诊断。实际录制、软件回放、仿真镜像与回音单独标识。检查自然独立的非目标轴响应以验证耦合和反馈语义。

采集静态基线、对照空闲、批准范围内的单轴偏置与回落、方向/速度响应、平滑带限激励、相邻轴和双臂交互、持有及收敛。具体幅值、速率、频带、时长和运行控制需在后续审批附件冻结。每轴报告 q、速度、请求、下发、可证应用、独立反馈及各自有效率、激励覆盖、信噪、限幅和耦合。辨识负责人按模型族和工位预先冻结最小样本数、频带、秩/最小奇异值、相干性和留出复测准则。历史轴解析成功和静态资格只登记到相应分级，缺动态证据轴组保留 BLOCKED。

**动态归因复验。** 静态偏差用已确认实际应用量后的稳定窗计算有符号 \(q_{\rm measured}-q_{\rm applied}\)，按进入方向、关节区间和负载分层，另报重复性与滞回。先用 C2-RT 独立锚点冻结时钟映射和误差界，再估计应用至物理响应的延迟。有界到达与应用时刻缺证时，仅报告可测总延迟或 UNKNOWN。对匹配的姿态、激励幅值与频带、方向和负载，固定时钟和静态偏差后，用响应衰减及幅相拟合所声明模型族的阻尼，以可区分的单轴与多轴激励估计非对角耦合。饱和、软件限速、串扰与激励秩不足各自标记。拟合及置信区间冻结后，在完整独立 HOLDOUT 会话以同一有效样本规则复验偏差、残余延迟、衰减/幅相和相邻轴预测误差，披露匹配与未匹配覆盖及不可辨识项。

## 6. 现场安全门及申请模板
