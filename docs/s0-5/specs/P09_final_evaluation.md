# P09 强基线、多种子、消融、一次独立 Test

## 1. 阶段与版本

P09 v0.1.1，初稿。

## 2. 目标

公平比较 B0–B5 与 Oracle，进行多种子、关键消融和一次独立验收。

## 3. 与主设计的关系

M6–M9 与 E1–E5。

## 4. 覆盖需求

025、026，整合 005–009、020、022–024、030。

## 5. 前置条件

P08 ACCEPTED，模型、P02/P03 共同评分目标及 P09 指标和非退化门、种子、分析脚本、算力及评估授权冻结。必须有 `FINAL_TEST_SEALED` manifest SHA、未使用来源的证明与访问日志。未满足为 BLOCKED，见 [历史使用与封存](../HISTORICAL_DATA_USAGE.md)。

## 6. 现有实现审计

S0-4 存量 val/test 曾周期性回放，其 Test 历史用途需调查。B2 兼容 adapter 先在 validation 确认。

## 7. 范围

最终多 seed、传统/学习和 PPO/SuperMimic，消融 14/54、意图、reward、Jacobian、双手、history、robust。

## 8. 范围外

看 Test 结果调参，挑成功片段，使用模型预测作为最终物理评分。

## 9. 输入契约

固定源、映射/可行目标、初态、扰动脚本、共同 scorer、checkpoint SHA 与环境预算。

## 10. 输出契约

不可变实验注册、原始 Test 分数/覆盖、消融数据、模型可信度结果、最终报告。

## 11. 数学定义

相对改进 (m_baseline−m_policy)/m_baseline，episode 配对不确定性及 seed 分层；模型 Jacobian 检查余弦相似度和范数比。

## 12. 架构与模块

共享物理评分入口，PPO 与 SuperMimic 独立训练；离线 Oracle 单列，实时版按延迟预算。

## 13. 实施任务

预注册主次效应与预算、运行回放、B0–B5 分析，报告全部统计与失败。

## 14. 预期文件与接口

计划 learning/supermimic.py、eval/final_compare.py、冻结 Test 指纹及分析 notebook 或脚本。

## 15. 单元测试

冻结门与 hash、指标分母、paired bootstrap、WM Jacobian 的真实扰动差分。

## 16. 集成测试

闭环跨算法真实执行、复现种子及 ablation，Test 数据访问和评估 provenance。

## 17. 实际运行

候选冻结后启动测试，保留所有进度、预算和截断，真实回放 score。

## 18. 定量协议

E3 主指标、20% 预设或已批准门、绝对挑战与全部安全非退化，按种子报告置信区间。两层目标与投影误差同轴报告。整体遥操作达标需端到端映射误差与功能对捏、双手几何等主指标达标。

## 19. 强制验收

公平 B0/B1/B1+/B2 可运行或显式揭示未满足项；充分证据支持通过才提请接受。Test 失败如实记录。

## 20. 失败处理

若测试失败，保留日志和快照；重启研发需新的独立终评设计。
