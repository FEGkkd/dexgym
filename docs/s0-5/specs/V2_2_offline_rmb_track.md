# v2.2 离线 RMB 与 Policy 优先候选实施规格

本文件定义 [DCR-010](../dcr/DCR-010_offline_rmb_first.md) 的隔离诊断。仅使用指定、已签 Train 母源。`s05.rmb.offline_diagnostic.v1` 为诊断候选，生产加载仍遵循 [正式 RMB 契约](V2_rmb_contract.md)。

## 预登记实现选择

| 决策 | 本轮默认及资格边界 |
|---|---|
| 执行方式 | C++ Teleop 内核和 Wuji SDK 加本地 MuJoCo。4 ms 计算一次原生命令提案，两个 2 ms 物理子步组成该段，五段对应 HMB 的 20 ms 周期。仅采用 HMB 已因果就绪的观察，逐实际选中 MANUS 源样本更新 Wuji。沿因果保持补齐 250 Hz 命令输入。原 ROS 约 120 Hz 回调及 250 Hz 计算调度等价由 Track B 验证。 |
| 模型 | 签名 XML `939b3651e2426e596eed482e70a68c2382720df1fd55b124aa5f0893b640e92d` 与其碰撞、惯性、驱动、地标依赖。既有 `CpuServo` 的 16 ms 臂滤波及 500 Hz 步进。滤波后的 `q_applied` 与重力补偿后的 MuJoCo `ctrl` 单列。历史原生 MuJoCo 模型仍在 Track B。 |
| 证明预算 | 保持签名模型 0.500 mm 基本净空和 2 μm 证明数值余量。8,191 次细分、18 层、单次最多 2 s，整根设置外部时限。已证明包围盒缓存须满足包含关系。实际物理量逐子步验证。预算耗尽单列。 |
| START | 使用稳定窗的末个已可见双腕与局部手型。每根只锁定一次。第 5 根诊断使用固定公共偏航规则。先稳双腕、再冻结目标分指推进。历史回放前需工程位置 ≤10 mm、姿态 ≤5°、稳定反馈和收敛的指令。直接内核保留已审核配置的原生 8° 余量。本诊断资格不继承先前 ROS 过渡中的 5° 左 J6 专用候选。 |
| 形态 | 保存原 Tracker、MANUS，另有腕代理、签名机器人本地骨长的候选形态。目标、掌代理、捏合与跨手向量由冻结人端输入得到。不得用执行 q、SDK 输出或跟踪误差重建目标。解剖及物理资格独立。 |
| 恢复 | 对拒绝请求验证保持上一已下发命令。保持有证明时照原物理时钟推进，后续有效 HMB 输入允许再次提案。失效切断活动历史。明确硬故障或无法证明保持时不推进物理，剩余行保留原目标及未执行状态。任何恢复不更新 START 变换。 |

## 数据、测试与门

第一次真实执行在 START 的首个右手无名指阶段触发物理速度保护，5.01918 rad/s 超过 5 rad/s。第二次诊断仅将 START 过渡手指请求限制到每 4 ms 0.015 rad，留出伺服响应余量。历史人体时间轴、历史名义控制步幅和物理限制保持。已验证的原 HMB 分区时戳有纳秒级舍入，替代精确等间距离拒绝的规则是在原 START 时间后固定偏移 1 μs 建立连续 20 ms 控制网格。记录原时戳及网格时戳，准入要求原时戳与未偏移网格绝对差 ≤1 μs。控制只使用对该稍后截止时刻可用的已签原记录。真正时钟断裂保留在计划分母并中止本候选的物理执行。

- 每分区保留原拍 ID、HMB 时钟及世代、原联合有效与五帧候选 mask。普通文件分区延续对齐、SDK 和仿真状态，原五帧候选分母独立。
- 原始及独立目标、名义子步、指令、应用、反馈、碰撞/净空和执行分类各自保存。缺失带 mask。非法命令仅在审计层可见。名义速度仅用相邻活动合法拍。失效、保持、恢复切断训练历史。可改善见证缺失保持 `UNKNOWN`。
- 源 ID、资产 SHA、几何配置、RMB 分片和运行命令同存。策略的最新反馈只能来自其当前 MuJoCo rollout。
- 首先处理根 `capture:b63bc72d2e8b2ee395e966f6`。技术验证需要合格 START、来源和全计划分母一致、原速处理与有效物理执行。若出现结构性阻塞，保留失败。六根沿用相同配置，首根技术验证通过后才推进。
- V1-B 可用合成数据验证有名 54 轴、因果五拍、B0/B54、CPU 和可用 GPU、学习 adapter 的实际物理 transition。全部合成结果隔离于正式 G-A、G-C0 和训练性能。
