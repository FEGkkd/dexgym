## 几何、数据和执行审查

- 机器人实测中性 Home 和人体 START 各有状态及证据。候选 `T_WH` 由适用的共同旋转及两侧对应解剖掌根的中点确定。比例恒为 1。逐手重新对齐、改原轴、混用 Tracker 原点和解剖掌根、或根据 IK 结果重定向目标均破坏该合同。以同一适用的 (R_{\rm cal}\) 作用于两手，才有依据检验点间距离及相对 SE(3) 的保持。
- 三例高误差见证显示 M1 与 Shared 在全局注册处已分歧，原始 Tracker 原点的间距仍保持；解剖和手指层另有固定安装、骨架形态的差异。历史 2026-11-18 腕部安装校准缺少各次录制当天独立确认。该档案可帮助限定软件诊断，物理资格仍待独立证据。Live 与 P02 签名模型只在已核验腕部条件下用于共同诊断，世界和局部手地标相差最高约 6.3 mm。[可视见证及敏感性](TELEOP_high_error_mapping_witnesses.md) · [模型和安全对照](TELEOP_native_nominal_replay.md)
- 99,562 个四层同域有效拍中，M1→原生 Shared、Shared→已发和已发→实测的腕位置 P95 分别为 693.28、79.11 和 18.66 mm。最差端到端位置的 4,979 拍中，4,972 拍的同侧最大位移链路在 M1 与 Shared 之间。过滤目标和求解器步目标相差 76.74 mm P95，该段需要区分工作空间塑形及限速。用一个共同变换证明构造性质，无法代替独立物理参考或 Servo 实测。位置向量只有在匹配的同腕、同拍与同帧才逐级闭合，距离分位数和 SO(3) 误差角分别计算。[分层数据](../campaign/evidence/teleop_full_start_handoff_layer_receipt.json)
- 已发只表明控制器发布，driver 接纳及实际应用、同拍反馈、独立合法路径和当前目标跟随证据应继续分列。旧原生回放固定身份的 399 个端点中有 154 个违反签名模型碰撞净空。同一批命令另外有 9 个通过签名模型但未通过 live 模型端点检查。保持真实命令所有权、STOP、反馈、J6/J7、驱动范围、连续路径和独立扫掠判定。主动覆盖排除合法 HOLD。[原生全身安全差异](TELEOP_native_nominal_replay.md#signed-whole-body-path-shadow)

## 待审设计边界

批准设计、六个 Train 母源的有界 Pilot、32 根全量执行、正式 RMB 准入和后续学习分别登记。第一阶段只允许本地历史复核、文档和合成验证。当前不启动 Pilot、原生回放、全量参考生成、训练、部署或硬件。已有 Campaign 授权的批准哈希和执行范围按其原身份保存。历史软件复现、原生成功和合成控制均不能作为新的人工批准凭据。

## 已复核的草案修正

| 审查项 | 复核情况 |
|---|---|
| Anchor 使用首个有效拍会遗漏稳定窗口 | DCR、几何和运行提案均采用合格尾随稳定窗口的终止拍，并分开记录不可核验的历史事件与明确存在但不合格的事件。后者不走重建回退。 |
| DCR 与实施草案的帧符号不同 | 已统一为人体世界 `H`、机器人世界 `W` 及左右求解基座 `B_s`。机读状态将机器人反馈的目标构造角色限制为实测 Home 的共同中点。 |
| 跨存储分区的连续会话可能改变 70% 成员 | 数据提案将跨分区状态延续限定为回放和连续性诊断，计分仍以原签名 `(partition,end_tick)` 候选窗为成员。 |
| 发布、应用和实测可能被混计 | 数据和运行提案均独立定义 `Q_ISSUED`、`Q_APPLIED`、`Q_MEASURED`，未取得 driver 应用证据时留 `UNKNOWN`。运行草案要求运动进展朝当前目标，并将安全 HOLD 排除在主动资格之外。 |

独立的本地合成检验已复算两种 split 的整数覆盖下限、合计分母及待审标志。非对称双手样例验证共同中点、相对平移和 SO(3)；镜像和逐手归零负控触发预期差异。以上检查未使用新人体数据或模拟物理运行。[几何提案](../specs/V2_1_home_anchored_geometry_proposal.md) · [运行提案](../specs/V2_1_home_anchored_runtime_proposal.md) · [数据和门禁提案](../specs/V2_1_home_anchored_data_gate_proposal.md)

从基线 Git 对象读取 E1 索引，先核对其 SHA-256 与 HMB manifest，再从分区证据重算 split 分母。以仓库检查器的入口函数独立验证实际待审状态和 9 个合成合法相邻迁移。7 个负控均被拒绝，包括提前打开 Pilot 或训练权限、伪造批准引用、提前推进阶段、缺少 Pilot 执行授权或标定资格，以及缺少全量构建的单独授权。合成回执只检验前置关系。[阶段一检查器](../evidence/V2_1_START_PROPOSAL/check_proposal.py) · [机读提案](../evidence/V2_1_START_PROPOSAL/design_candidate.json)
