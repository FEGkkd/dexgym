# DCR-002 历史 HMB 与真实时钟资格分门

状态为依赖调整范围已获项目用户授权，技术门及后续开工须分别签核。适用既有 DCR-001。原结论仍见 [P01-C 验收](../reports/P01_C_acceptance.md)。

| 项 | 记录 |
|---|---|
| 原设计及问题 | 原 C1/C2 同属 P01-C。已见七个母源的软件几何复验，原 C2 真实时序 BLOCKED，VERIFIED 拍为 0。独立历史补证和明确定义的仿真时钟有不同工程用途 |
| 批准的调整 | C1-GEO 验收软件几何，C2-SIM 验收代理单调时轴与模拟到达语义，C2-RT 独立验收物理捕获、控制节点到达及误差界。C1-GEO 和修订 C2-SIM 实测通过并获人工签核后，可另行授权 P01-D 的历史仿真用途 |
| 替代方案 | 保持单门会阻塞有界仿真研究。把历史 collector 时间直接作真实到达会虚增时钟资格。采用用途隔离，保留两项独立实机补证义务 |
| 影响需求 | S05-REQ-001、003、009、012、015、018、029、030。最终 54 DoF、因果、精度、强传统基线、鲁棒性和安全要求继续适用 |
| 风险与缓解 | 将模拟覆盖误报为实机延迟，或将软件外参重建视为物理校准。产品适用范围写入 manifest 和阶段门，真实端点及基座用独立量测验收 |
| 签核 | 本次用户明确授权上述依赖变化及 P01-C 审查修复。C1-GEO/C2-SIM 独立待技术证据和人工审核；没有新阶段、采集、发令或训练授权 |

## 阶段和允许用途

| 阶段 | 必要前置 | 允许用途 |
|---|---|---|
| P01-D | C1-GEO 与 C2-SIM 均 PASS、P01-C 历史 HMB 资格人工 ACCEPTED、P01-D 单独授权 | 冻结 SIMULATED/PROXY 历史开发产品的候选 QC、split、用途与边界 |
| P01-E | P01-D ACCEPTED 及另行授权 | 只构建由 D 批准及标记的历史产品。拒收未知域与未审录制 |
| P01-F | P01-E ACCEPTED 及另行授权 | 独立审计产品域、部署不可用标记、来源、误差和范围 |
| P02 | P01（HMB 路线）ACCEPTED 及另行授权 | 用合格 HMB 做人体几何、仿真意图、可达性。真实基座注册另证 |
| P03 正式启动 | P02、P01-T、C2-RT 和物理 robot-base 注册分别 ACCEPTED，另有 P03 人工授权 | 才可宣称具备用于正式基线的真实数据资格。实机操作仍需独立批准 |
| P09、P10、正式 RL | 原门继续有效，正式 RL 依赖 P03 成功，P09 保留独立 Final Test 封存 | 历史覆盖和模型到达时间禁止用作真实端到端时延证据 |

C2-RT 及 robot-base 目前 BLOCKED，P01-T 和 Final Test 同样 BLOCKED。原 C2 BLOCKED 和 0 VERIFIED 拍归档。PROXY 是有记录的观测替代量，SIMULATED 是显式模型，VERIFIED 需真实证据校验及误差界。[C2-RT 补证规格](../specs/P01_C_RT_clock_qualification.md)
