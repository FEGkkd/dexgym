## Candidate accounting

Report the unchanged 32-root, 308-partition, 116,613 planned-frame denominator and the signed joint-valid denominator by split. The original metric classifies legal bilateral exact-IK nominal references. The candidate additionally asks how often the actual existing causal kernel can produce an independently legal, fresh active reference on both sides. These two coverage definitions differ and must appear side by side in every comparison. The proposed active-coverage numerator can include accepted rate-limited active commands. It excludes stationary recovery at an unmet goal, HOLD, fallback, failed, missing and unknown rows. A successful native IK call or collision-free pose alone is insufficient. Keep raw SDK direct exact results and per-side causes. Report HOLD, fallback, failed, missing, projected/limited and recovered status counts, rate limits, tracking displacements and continuous active histories. Apply the same unchanged numerical threshold of 85% separately to each split's signed denominator when reporting the candidate. No diagnostic result creates a gate receipt.

## Kernel parity and downstream obligations

The paired validation supplies a current canonical goal and previous accepted reference to the exact phase1 `process_targets` and `finalize_command` operations. The cached run uses a deterministic signed-home NSP latch per generation and copies the previous verified command into the virtual measured-state slot. The path-coded experiment retains original goal, intermediate targets, raw output, issued output, clock cutoff, and acceptance for all substeps. A global native denial latches until the next explicit generation and freezes all 54 axes. Local denial, admitted protected fallback, and unavailable-input hold have distinct outcomes.

The future online provider must use the identical native seam and measured-state timing contract. For the same canonical input bytes, the same previous accepted command, and the same measured state, compare SDK and issued commands, reasons, timing and reset boundaries before using the policy runtime. Separately quantify differences due to recorded HMB sampling, initial START, per-message Wuji filtering and actual feedback. The cached run provides causal-prefix and same-state native evidence. Actual online equivalence requires the approved MuJoCo Teleop replay with the two designated recordings.
