# DCR-003 专项研究补证

项目用户已批准 P02 Workspace Mapping & Oracle Refinement 专项研究。正式评分域、模型外部物理注册以及终验阈值的变更仍待人工审批。[原 DCR](DCR-003_p02_workspace_registration.md) · [本轮报告](../reports/P02_review_refinement.md)

| 研究选项 | 量化证据 | 提交审核的用途 |
|---|---|---|
| M0 原共享刚体 | Validation 全量径向下界 >3 mm 为 27.54%。原 32 主样本的多任务 P95 随预算 90→1000 仍为 209.55 mm | 保留原意图和原结果，作为每次比较的共同审计列 |
| M1 多姿态共享刚体 | Validation 超界为 14.36%。保留双腕间距和相对跨手向量，原主样本的绝对目标十指最大位移中位数 156.80 mm | 历史仿真静态开发的第二套候选目标。报告 M1 误差、原 M0 上的误差和绝对位移 |
| M2 有界共享尺度 | Validation 超界为 12.35%。原主样本腕间距中位收缩 50.50 mm，改变跨手及异指几何 | 诊断映射与域外覆盖，另行审批后才有资格进入正式契约 |
| Minimax | 主队列 M1 目标的 3 mm 同拍 24/32，捏合与相对腕 P95 分别为 110.12、760.14 mm | 提供每个目标的最差指可行上界，与严格径向下界并列。多任务 Oracle 保留完整功能目标 |
| 平滑捏合 | Validation 左手入阈一步变化 P95 从 20.57 到 11.34 mm，活跃捏合向量误差 P95 增为 8.68 mm | 连续性与对捏保真的诊断候选，仍需另行复核合法机器人 FK 表现 |

上述拟合只消费开发 Train。Validation 是冻结后的比较；原 HMB、split、QC、失败和径向域外输入全部保留。M1/M2 按自身目标误差下降的幅度与回评至原 M0 时的结果不同，正式协议须保留原 M0 列以量化这项差异。评估数据冻结后不得依控制器执行轨迹改变可行评分目标。

提交的 M1 共享开发候选绑定同一已审模型、原主队列和尾部的来源键、映射目标、合法多任务 Oracle 重建的可行目标、逐点投影与独立离线 q。正式采用还需用户完成目标范围审批。独立的 P02、P01-T、C2-RT、物理 robot-base 四项 ACCEPTED 仍是 P03 前置。用户未批准 P03、训练或机器人动作。[候选清单](../evidence/P02/refinement/scoring_freeze_candidate.json)
