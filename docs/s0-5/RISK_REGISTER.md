|---|---|---|
| R01 仓库版本分叉、依赖遮蔽 | main 不含 S0-4，发布 commit 和运行快照不同，运行需专用 overlay | P01 建工作分支与依赖快照，P04 锁定版本；保留用户 diff |

| R06 臂/手实际 Servo 不一致 | S0-4 CPU/GPU parity 仅为历史短窗仿真，硬件臂和手通道异步 | P03 独立定标两组，P08 验证实际干预，P10 独立外测 |
| R07 时限、碰撞近接与发令 | 在线 IK、FK、演员推理和安全检查共享实时周期 | P03 中止预算与路径检查，P07 压测，P10 watchdog、HIL、独立授权 |
| R08 设备及磁盘预算 | RTX 5090 共享并有占用，Ubuntu 根磁盘采样剩余约 29 GiB | P01 用首批样本估算全量峰值；P04/P09 调度，不改现场训练任务 |
| R09 模型与奖励投机 | 长尾、平稳但偏移、提前失败、WM 预测利用风险 | P04 数学测试与终止对照，P05/P06 静动门，P09 真实评估与 WM Jacobian |
| R10 基线不可比较 | 旧 B2 脚本依赖版本、内部目标/动力学和滑窗与新协议不同 | P03 输入和动力学等价前置验证，P09 若不可比记阻塞 |
| R11 未验证真机精度 | FK、外测、硬件安全、操作许可是独立证据 | P10 各级签核，先 Shadow/HIL 后授权真机 |
| R12 强基线可能已足够 | RL 只能靠公平对照与不确定性证实额外收益 | P03 调优基线，P09 跨种子配对，按结果报告无收益或负收益 |
