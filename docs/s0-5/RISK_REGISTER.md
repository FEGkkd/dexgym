# S0-5 风险登记 v2.0.1

| 风险与触发 | 责任阶段 | 证据及处置 | 剩余风险 |
|---|---|---|---|
| HMB 身份、角色或产品资格不符 | V1-A | 复验已有哈希、root split 和每拍引用。隔离，阻塞所有使用者。 | 只有历史仿真等级 |
| M1 跳变、腕目标失配或 SDK reset 后伪连续 | V1-A | 分区/失效边界逐拍证据。保留原目标与故障，另提 M1 新用途签核。 | 模型域和记录域有差异 |
| 残差活动域有限，困难段改善不充分 | V1-A/C2 | 冻结共同可改善域、完整域、UNKNOWN 和尾部。预算内课程调节后重新回放。 | 样本和物理可达性 |
| SDK FK 代替人体意图暴露不足 | V1-A/B/D | 独立目标、功能退化和投影误差成对计分。主标签锁定。 | 人体形态差异 |
| 54 轴映射、速度、耦合或路径错误 | V1-B | 单轴、组合、路径及故障测例。硬错误阻塞执行和导出。 | 碰撞网格质量 |
| Servo 记忆/有效动作与 imagination 对不上 | V1-B/C0 | CPU/GPU 回放、状态/动作时序及区间等效量校核。未通过时重做接口与数据。 | 简化动力学 |
| WM 样本泄漏、手指无激励或 Actor 利用 | V1-C0/C3 | 按来源/时块隔离，核对每轴敏感性、尾部误差与真实 rollout 差距。暂停 Actor，重新资格化，预算耗尽停止。 | 单种子和有限探索 |
| 验证集反复选型产生偏差 | V1-D / 后续科研 | 事先冻结评估、预算与候选数，发布所有尝试，Final Test 按根封存。 | V1 属于开发评估 |
| 实时名义与缓存有偏移、回退越权 | V1-D / Teleop 集成 | 独立进程、盲 Replays、命令所有权、无 Bank、实际零残差差异明示。 | 实机时间与接入待测 |
| 显存、资源竞争或运行中断 | 全线 | 查现有进程和磁盘、净新增计费、保存真实 PID 和 checkpoint，在剩余预算内恢复。 | 主机占用变化 |
| 状态伪造、放宽指标或遗失证据 | 全线 | 签核与技术门分离，冻结 SHA，独立复核，拒绝失效和超预算状态。 | 签核主体需人工核验 |
| 硬件或终评错误放行 | 后续 | P01-T、C2-RT、外部计量、物理注册、Servo、Final Test 和现场权限专门门禁。 | 物理挑战仍待实证 |
| 低误差域被训练后选择或只有易姿态 | A/B/C0/D0 | 训练前锁独立静态及连续 Servo 见证与来源支持。不足登记失败或不确定。 | 真正动态可跟踪性仍须实测 |
| 录包重放角色混淆及历史重叠 | D1/D3 | 仅允许人端与必要事件写入隔离图，记录独立新反馈及 source/derivative 审计。 | 历史选型重叠限制外推 |
| 实际 Teleop 适配和离线分布不一致 | D2 | 先核 START、坐标、时钟、Builder、SDK、Servo 和投影。修复后重跑，继续训练由诊断证据触发。 | 可复现的覆盖缺口仍可能存在 |
| EgoPro 数据伪装为真实传感器或损害 Teleop | E0–E3 | 独立身份与 mask，重验 54 轴 WM，原静/动态门和两包回归未保留时退回 Policy-T。 | 无匹配补训时只得工程归因 |
| 诊断报告冒充推荐或预算重复 | D/E | 独立标志/级别及合计计数，超额拒绝。 | 小预算下可交付较低等级 |
