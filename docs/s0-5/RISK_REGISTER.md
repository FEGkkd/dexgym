# S0-5 风险记录

| 风险 | 证据及影响 | 处置与责任阶段 |
|---|---|---|
| R01 仓库版本分叉、依赖遮蔽 | 已建立独立 `s0-5` checkout 和指定解析环境，主仓库与 Teleop 用户版本保持隔离 | P01 重跑模块身份校验，overlay 变更触发重新冻结；P02/P03 另核模型/Servo |
| R02 谱系泄漏与录包混杂 | 两种 MCAP 已抽样；replay 可含 raw MANUS/Tracker，历史 test 有重复评估 | P01 按根、历史角色和丰富采集线索治理；独立终评未证明，P09 必须封存及计账 |
| R03 时钟及延迟 | 有 header、SDK、MCAP 与部分采集域，历史控制节点接收戳未证实 | P01 分两种对齐和时钟等级，P03/P07/P10 实测异步与故障 |
| R04 意图映射可能损坏对捏/配对 | 旧映射用骨段方向和模型骨长，不能从 FK 拟合直接推断人意图保真 | P02 多手型测试，对捏及跨手扫描，保留 raw 与估计误差 |
| R05 误差超过静态可达上限 | 对齐 S0-4 难定点约 38–40 mm，受限动作、标定、动力学或求解均可能参与 | P02/P03 逐层解除约束、hard pose 与真实 Servo 对照，必要时 DCR |
| R06 臂/手实际 Servo 不一致 | S0-4 CPU/GPU parity 仅为历史短窗仿真，硬件臂和手通道异步 | P03 独立定标两组，P08 验证实际干预，P10 独立外测 |
| R07 时限、碰撞近接与发令 | 在线 IK、FK、演员推理和安全检查共享实时周期 | P03 中止预算与路径检查，P07 压测，P10 watchdog、HIL、独立授权 |
| R08 设备及磁盘预算 | 当前资源独立采样见执行基线，和原始 P00 采样不同 | P01-D 量测字节/帧、RSS、瞬时写放大并锁峰值；P04/P09 另排 GPU |
| R09 模型与奖励投机 | 长尾、平稳但偏移、提前失败、WM 预测利用风险 | P04 数学测试与终止对照，P05/P06 静动门，P09 真实评估与 WM Jacobian |
| R10 基线不可比较 | 旧 B2 脚本依赖版本、内部目标/动力学和滑窗与新协议不同 | P03 输入和动力学等价前置验证，P09 若不可比记阻塞 |
| R11 未验证真机精度 | FK、外测、硬件安全、操作许可是独立证据 | P10 各级签核，先 Shadow/HIL 后授权真机 |
| R12 强基线可能已足够 | RL 只能靠公平对照与不确定性证实额外收益 | P03 调优基线，P09 跨种子配对，按结果报告无收益或负收益 |
| R13 旧版 CDR schema 演化 | 合并 MCAP 的部分记录与当前 ROS message overlay 不兼容 | P01-B 用录包内 schema hash 选择解码器，验证逐格式遥测覆盖；漂移字段显式标注 |
| R14 MANUS 源时间字段物理单位与重复 | SDK 发布值原样进入 ROS 字段，同字段名不能证明物理单位或关联至控制器时钟 | P01-B/C 保存原值、验证时基及重复，分流设备时间、宿主机接收时间和控制节点到达时间 |
| R15 不同字节的隐性谱系与遗失历史证据 | 重编码、裁剪、慢放、仿真复播可能改变 SHA，旧归档未保存完整母源身份 | P01-B 用内容证据核实候选，开发划分按可追溯母源隔离，Final Test 要求独立封存 |
