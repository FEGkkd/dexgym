## E1 冻结与公平性

P03 正式启动前验收 P01-T 的实际硬件、时序和动态资格。该依赖来自 DCR-001。现有精度、因果、鲁棒、安全和强基线标准继续适用。[DCR-001](dcr/DCR-001_p01_hmb_telemetry_dependencies.md)

P00 定义指标和设计。P01 锁定 source lineage、数据切分、时序来源与访问日志。P02 确定意图与可行性目标、统一目标由冻结参考服务生成。P03 用 train/validation 建立 B0/B1/B1+，冻结场景、评分掩码、训练与推理预算、统计规则、相对收益阈值与允许退化边界。P09 冻结候选权重、种子与方法后一次正式启用 Test。历史 S0-4 的 val/test 跟踪结果仅用于审计，已用数据如不能证明独立则从最终 S0-5 test 谱系排除或新采。Test 失败保留；再研发后建立独立的新终评机制并记账。

P02 保存 `mapped_intent` 和 `feasible_scoring_target` 的共同生成版本、calibration、mask 和 provenance。P03 冻结 P09 主指标、失败分母和非退化门，并固定两种评分目标。P09 进入前要求 `FINAL_TEST_SEALED` 的母源及访问审计。当前资格缺证时，终评保持 BLOCKED。[历史用途与资格](HISTORICAL_DATA_USAGE.md)

所有在线控制器共享人端输入流、空场景模型、初态抽样、动力学/Servo、控制频率、时钟、约束、安全投影接口、独立评分目标、扰动脚本与评分工具。B0 和 B2 的各自入口按其原有 observation/action 语义计算命令，在同一执行/评分接口记录。B2 保留其自有 SDK 点作为内部输入，外部对同一 mapped/feasible 目标评分。需验证原 14 维/54 维格式、时间与模型兼容；若无法同条件运行，记录 BLOCKED，历史数字不能填入对照。各控制器可以有自身名义算法，超参数选择用共同的验证条件与记录预算。Oracle 使用同目标与运动学约束，单独报告其静态可达下界和求解预算，不作为实时方法。

## E2 场景与控制时间

| 场景 | 基本条件 | 记录 |
|---|---|---|
| 静态静止与收敛 | 易/难姿态，初始臂、手和混合偏差的分层配对，同目标保持，难姿态只在 validation 选 | 最终位置误差、首次持续进入阈值的时间、末窗低速 RMS、饱和与投影 |
| 臂手补偿与单指 | 独立指运动、同腕换手型、同手型换腕、同步与异步两手 | 指级与手位姿误差，54 维响应，在 B2 的同条件证据 |
| 精准对捏与相对几何 | 左右手分别的拇指与四指、分离与接近、跨手目标 | 对捏向量与距离、跨手相对点和腕位姿 |
| 动态与困难运动 | 原始速度、连续未见 episode，难段按训练/验证统计冻结规则 | 以当拍指令为准的执行误差和真实时间轴误差、P95/P99、失败与完成 |
| 变化和恢复 | 停止、反向、速度变化、可行目标切换、独立肢运动、失联和再捕获、定义小扰动 | response latency、过冲、收敛、恢复率、失效回退 |
| 长时与鲁棒 | 全 episode 仅初始 reset、全长在线流，多强度时钟/传感/物理扰动配对 | 全段覆盖，碰撞、失败、饱和、延迟、按扰动等级分层 |

静态初始候选为 100 拍，总 2 s，末 25 拍计分，未达静止按原规则失败，明确全轨迹与末窗结果。收敛候选为所有指尖进入 3 mm 且保持至少 5 拍，记录到达 10/5/3 mm 的迟滞。恢复时间从扰动结束到进入事先定义的阈值并保持规定窗口，初始偏差幅值、方向、测试窗和 timeout 在 P03 前冻结，未恢复为右删失并单列。长时运行、静态时长与难段目标覆盖按 P03 实测后审批。物理时间的精度一律不事后平移；相关峰可作为附加诊断但不影响原时间指标。

## E3 配对、计分与失败披露

每帧按十指独立的欧氏距离报告，主序列 e_max(t)=max_i ‖p_meas_i−p_target_i‖，再跨帧取 P50/P95/P99。每指与十指平均序列同样报告。供复现的默认分位数为线性分位插值（NumPy method=linear），同时报告纳入帧数。mapped、feasible、projection 三条序列分别存储和评分。腕角用 SO(3) 夹角，平移欧氏；对捏报告向量误差与距离误差；跨手使用 E2 冻结配对向量误差 P95，同时保留相对腕平移/姿态。静态指尖速度 RMS 用十指各拍因果相邻差的模长平方均值开根，另报单指；定点距离不纳入速度统计。动态响应记录发布、生效、响应到阈值的真实时间，Actor 推理 P99 使用目标平台固定 batch=1、时间区间含同步，预热单列；端到端延迟从人端采样到物理响应，采用已测同步时钟。

逐帧拆分执行误差（measured−feasible）、投影误差（feasible−mapped）、映射保真（人体意图对机器人映射的归一化几何）和端到端意图误差（measured−mapped）。对捏与双手相对几何独立计分，并注明目标层和物理时间轴。整体遥操作达标必须用端到端意图、功能几何及冻结的非退化门共同支持。P03 记录采集/传输、同步、映射、名义求解、Actor、投影、发令、Servo 和物理响应分段及全链路 P50/P95/P99，逐频率报告精度、deadline miss、触发回退及恢复。未知或模拟时钟单列，不能作为真实链路统计。

计划帧是预先冻结的共同有效目标/测量窗口，规则在查看任何方法结果前固定。不可行目标仍评估 mapped，feasible 无效按目标覆盖率单列，不作执行失败。失败硬停时从发生当拍起记录原因，后续计划帧标 unscored。共同目标/测量无效帧独立计数，控制器状态无效属于控制失败。十指同拍 3/5/10/15 mm 到位率以全部计划帧为分母，硬停/失效/缺分均不达标。分位数同时输出实测帧分位与将控制失败缺分填为 +∞ 的复合分位，+∞ 序列用 nearest-rank 避免插值歧义并同时展示原序列同规则的值。碰撞率、碰撞硬停数、约束介入率、饱和率、姿态与轨迹完成率一起报告。规定接触几何、阈值和身体类别，防止把计划的几何接近误作穿透。公开统计分母、原始 episode 分层和所有失败 case。

比较以共同 source episode 为独立单位，配对以源 episode、初态、扰动种子；报告总体帧汇总与 episode 等权汇总，长 episode 主导性单列。差值与改善率 bootstrap 重采源 episode，并展示每训练种子方向及跨种子不确定性。建议至少 3 独立训练种子，最终种子数与预算 P03/P09 冻结。主指标为动态和连续困难段 max-ten-tip P95，比较 B1+，预注册最小收益和容许的其他性能变化。无法得到有限复合 P95 时报告失败与覆盖，禁止将覆盖损失当精度改善。

## E4 挑战目标及判据

| 指标 | 研究挑战 | 适用条件 |
|---|---:|---|
| Static max-ten-tip P95 | ≤3 mm | 静态末窗，mapped 与 feasible 分报 |
| Dynamic max-ten-tip P50 / P95 / P99 | ≤2 / 5 / 10 mm | 原速、全 episode 真实时间轴；同拍执行另报 |
| Hard-motion P95 | ≤10 mm | 冻结连续难段，以十指最大误差聚合 |
| Pinch geometry | ≤2 mm | 预注册的对捏向量误差分位；候选为 P95 |
| Bimanual relative error P95 | ≤3 mm | 冻结的跨手相对点向量 |
| Static fingertip speed RMS | ≤1 mm/s | 独立于最终位置，末静止窗 |
| Small-disturbance recovery | ≤300 ms | 振幅和恢复判据冻结后判断 |
| Actor inference P99 | ≤5 ms | P03/P10 确认目标平台与测量范围 |
| End-to-end latency | ≤50 ms | 原始采样到物理响应；候选 P95，延迟分布全报 |

同时展示映射、执行、端到端物理分量。绝对挑战与相对收益分列；20% 动态与困难 P95 改善为候选，P03 结束后、RL 正式训练前批准。P02/P03 发现硬约束无法满足时保留原标准，提交 DCR，明确投影、测量噪声、动态带宽、延迟或算法影响。报告统一保存每帧与每 episode 计分，记录评估版本及 manifest 和 Servo 哈希。

## E5 消融、泛化和失效

预注册主对比和较小的消融预算。最低设计比较 14/54 维（同基准，手自由度通过 mask 消融），SDK FK/mapped intent（外部共同评估目标保持一致），单/多尺度，含/不含 Jacobian、双手目标、history，nominal/robust，传统/学习及 PPO/SuperMimic。相同真实环境 transition 或明确预算不平衡，同时报告计算开销与资源。域随机化用扰动前后实测响应来证明各通道干预，按单因素与组合分报。外部测量缺失时仅报告编码器 FK/仿真值。
