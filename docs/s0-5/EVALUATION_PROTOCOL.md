# S0-5 评估协议 v2.0.0

状态为 `DRAFT_READY_FOR_REVIEW`。V1 门槛及定标规则随设计候选提交。V1 结果属于单种子、历史开发数据上的 MuJoCo 仿真证据。正式物理评分、独立终评和真机资格各自审批。[总体设计](MASTER_DESIGN.md) · [阶段路线](ROADMAP.md)

## E1. 配对对照与冻结

| 方法 | V1 证据与比较范围 |
|---|---|
| B0 | 读取同一 `CACHED_CAUSAL_NOMINAL_REFERENCE`，残差固定为零，使用共同动作解码、安全、仿真 Servo 和实测读取接口。 |
| B54 | 相同参考与环境，SuperMimic 训练的 54 DoF Actor。仅在训练预算内拟合，权重选择依据独立实际 MuJoCo 回放。 |
| B14 | 若有预登记预算，固定手组残差为零。匹配初态、Train 分布、监督、采样、训练引擎、checkpoint 选择和真实 transition 预算。报告算力及有效激励差异。V1 若未运行有效匹配对照，报告 B14 为 `NOT_RUN` 并保留 14/54 DoF 学习比较待验。 |
| 实时 Teleop B0 | 在后续集成中，从实际合法输入流运行旧系统和在线旁路，核对命令所有权、时钟、START 和输出，再比较同后端与安全边界的残差 Policy。单列其资格与来源。 |
| 可选后续 | S0-4、PPO、不同名义控制器（可含联合 IK）、Oracle 等需各自预登记比较问题和预算。同条件才进入公平对照表。历史不同目标和动力学的数字只引用作背景。Oracle 作为可达诊断记录，注明预算与 UNKNOWN。 |

每对回放共享 source root、partition、连续窗口、首拍状态、Servo/model SHA、时钟与外生故障计划、硬安全规则、不可变评分目标和扰动 seed。共用 `q_requested`、`q_issued`、`q_applied`、实测状态和失败记录。零残差对合法命令对照须从同一命令初态测试，另用非法名义指令和输入失效负控检验回退一致。训练仿真的目标与独立 scorer 使用同一映射版本，通过源 UID、tick、坐标转换与目标 SHA 对齐，评分器从冻结输入独立得到目标。

先用 Train 定标、固定评分器和采样规则，之后登记 Validation 配对表、主/次指标、缺失处理、候选挑选规则及训练预算。共同可改善域在正式 Actor 训练前冻结，依据 V1-A 的严格排除与合法残差改善见证，对 B0/B54 共用。困难连续域使用预登记几何、运动和名义诊断规则，封存全部母源、窗口和 SHA。旧 HMB Validation 可以用于工程选择，所有访问进入台账。发布前固定 Actor SHA 后另跑独立回放复核，不把工程 Validation 复跑宣称为独立新数据。Train 拟合归一化和参数，独立 Final Test 在封存前保持 `BLOCKED`。[历史用途与独立性](HISTORICAL_DATA_USAGE.md)

## E2. 场景、计分时点及有效域

| 场景 | 运行与评分 |
|---|---|
| 静态定位 | 每姿态候选保持 100 拍，末 25 拍计主分，记录全程过冲、恢复、末窗速度及是否稳态。按预登记小幅臂、手、混合初态偏差配对，覆盖单指、拇指对四指及腕相对几何。 |
| 原速动态 | 原始时间轴、逐连续轨迹只做一次初始 reset。报告单侧、双侧、手型变化、停止、反向，以及冻结共同可改善域、完整有效目标域和困难连续域。 |
| 功能几何 | 每侧拇指与其余四指，各固定跨手同指及异指集合，双腕相对平移和 SO(3)，各腕本地四个有名地标。由共同输入预登记功能事件适用掩码，按事件及左右侧分层。 |
| 保持、回退与恢复 | 固定 HOLD、失联、晚到、超时和恢复注入位置。报告停机与恢复状态，实际响应达到阈值并持续 5 拍时记录首次恢复。未恢复为右删失，保留时限。 |
| 有界仿真扰动 | 在冻结幅度内改变 Servo 或状态，单因素及组合分别报告，实际测到每项扰动的响应。物理随机化、真实端到端时延适用后续计划。 |

按任务绑定 `tick_id`、命令标识、当拍目标和反馈时点。评分以实际 MuJoCo 状态和相同仿真原始时间轴为准。命令对应后态评分与同时间轴评分分别标示。允许附录报告相关峰和滞后诊断，主指标禁止任何事后时移。静态收敛另报进到 10/5/3 mm 并连续维持五拍的时间。小扰动恢复以实际合格样本和持续窗口计时，实际独立硬件测量沿用冻结的事件与时钟规则。

计划域包含所有原定拍，`raw_valid`、`nominal_valid`、严格排除、UNKNOWN、共同可改善、困难域及可行见证掩码分开。完整有效目标域仅依冻结输入决定，保留不可改善、严格排除、名义失败和 UNKNOWN 但有几何目标的拍。无 mapped 几何时单列输入覆盖，仍保留在全计划同拍命中分母。可行投影缺失不影响 mapped 评分，控制器导致的反馈缺失、非法输出和硬停保留为方法失败。已触发硬停的轨迹继续登记剩余计划拍为方法失败缺分，禁止为补齐得分在中途 reset。独立故障注入、共同设备不可用或评测设施故障按预注册规则记入原因，附所有失败与裁决记录。

## E3. 数学和分母

设实际十指世界点为 $p^i_t$，冻结目标为 $g^i_t$。先计算每拍 $e_t=\max_{i=1}^{10}\|p^i_t-g^i_t\|_2$，再跨拍求 P50/P95/P99。各指、十指平均、左右侧分别输出，同拍 ≤3/5/10/15 mm 的分母为该场景**全计划拍**，缺分不达标。观测分位数采用 NumPy 线性插值，另以 nearest-rank $x_{\lceil pn\rceil}$ 报观测分位数和失败复合分位数。后者在各冻结目标域把方法原因缺分记为 $+\infty$。JSON 用 `null` 加 `NON_FINITE` 状态表达非有限值。

拟合目标层与评估角色固定：

| 列 | 计算与资格 |
|---|---|
| Mapped Human Intent | 实际 FK − 同拍共同映射目标。V1 主判据。 |
| Nominal Geometry | 实际 FK − 当拍名义 FK。名义参考缺失时登记覆盖。 |
| Optional Feasible Geometry | 实际 FK − 独立可行见证几何。只在见证有效时报告。 |
| Projection Error | 独立可行见证几何 − mapped。记录见证版本、约束及未知。 |
| Mapping Fidelity | 原始人端几何与机器人映射几何，统一坐标及适用的尺度归一化之后比较。使用有名地标、对捏和双手关系。 |

向量分解仅在相同关节模型之外的同名几何点、同坐标系和同拍时比较，逐向量验证 `actual−mapped = (actual−feasible) + (feasible−mapped)`。各向量的范数和分位数各自计算。腕旋转用 SO(3) 测地角，局部手型用对应机器人掌系 P 中的 40 点 RMSE（如从腕系 U 输入，先按冻结的 T_UP 统一转换）。冻结 pair list 中对捏和跨手向量按各自定义的世界系/机器人掌系 P 求差，各拍对适用目标取最大，每侧及每对另报。对捏距离误差为距离差绝对值。双腕相对平移与转角分别通过左腕系中的相对 SE(3) 计算。末窗静止速度 RMS 用闭环十指逐拍位置差除以实际相邻时间差的模长平方均值再开根，时间不连续或跨 reset 的差分无效。功能误差复合分位数沿用适用掩码和方法失败规则。

主门用帧汇总复合分位数，另外报告每 episode 分位数及源等权统计。相对改善率和差值按 source root 配对 bootstrap，候选 10,000 重抽样和双侧 95% 分位区间，配对中任一方法失效仍保留。源少和单种子时报告分布、有效母源数、每源方向和区间的局限。保留所有轨迹长度、分母、子场景/功能覆盖、方法失败拍、失败事件和完整 episode 数，避免用长 episode 掩盖少数来源失效。

## E4. V1 工程验收

**Functional Gate** 要求 RMB 谱系、54 轴真实仿真作用、合法零残差等价、Actor 因果性、SuperMimic 实际采样和更新、独立 World Model 资格、安全/奖励/终止/reset/history 正负控均通过。导出、独立进程推理和连续闭环运行分别记录。资格按照 V1-D 的交付等级独立判定。

| Performance Gate | 候选判据及分母 |
|---|---|
| 静态位置 | 冻结有效静态目标域末窗 mapped max-ten 复合 P95 相对 B0 改善 ≥10%。 |
| 原速动态位置 | 冻结共同可改善域 mapped max-ten 复合 P95 改善 ≥10%，20% 为 V1 追求值。 |
| 完整有效目标域 | 原速动态 mapped max-ten 复合 P95 增量 ≤5%。B0 <0.25 mm 时使用拟议绝对增量 ≤0.25 mm 并单列门型及基线值。 |
| 控制失败 | 完整计划动态、静态分开，各场景失败拍率增量 ≤1 个百分点。同一拍多种失败只计一次，另报故障事件率和剩余失败拍。预登记输入故障只有回退协议失效才记控制失败。 |
| 功能非退化 | 适用场景的 mapped P95 对捏向量、对捏距离、局部手型、跨手向量、相对腕平移分别满足 `B54 ≤ B0 + max(5%×B0, 0.25 mm)`，相对腕旋转用 `max(5%×B0, 0.25°)`。按预登记适用掩码取分母。 |
| 静态保持 | 末窗十指速度 RMS 增量 ≤ `max(10%×B0, 0.10 mm/s)`。失败仍进入 E4 的失败与位置门。 |
| 饱和和安全介入 | 无硬安全违规。任意轴饱和（归一化请求绝对值 ≥0.98，或被残差包络裁剪）及非硬安全介入分别按完整计划拍报告。B0 的零残差无自身饱和，B54 任意轴饱和率 ≤2%，安全介入率增量 ≤2 个百分点。附臂、手、单轴和触发原因统计。 |
| 推理 | 目标主机 batch=1，Actor P99 ≤5 ms 为挑战指标。固定核心/设备/线程、warm-up、同步范围和并发负载。记录 ≥10,000 次采样的 P50/P95/P99/max 和实际控制 deadline miss。V1 独立运行按运行时契约的控制 deadline 和回退通过。 |

相对改善 `(B0−B54)/B0` 只在两者有限且 B0 ≥0.25 mm 时定义。B0 更接近零时报告绝对差，同步检查 B54 不超过 `B0+0.25 mm`，该项登记为 `INCONCLUSIVE_NO_HEADROOM`，等待另行批准比较方案。用于收益或非退化门的复合量有任一非有限值，或者必要场景样本量未达冻结值，登记门 `INCONCLUSIVE` 或 `FAIL`，列出原因和失败覆盖。两个收益门及全部非退化门均通过才提交 `SIM_RECOMMENDED` 候选。条件不足时按实际已验证等级交付。机制及数值详见 [评估参数登记](specs/V2_parameter_registry_evaluation.md)。

## E5. 正式科研验证与物理挑战

独立终评在预注册多种子、同条件基线、关键消融、推理预算、统计检验、非退化门和目标 SHA 后才启动。最低建议三个独立训练种子，冻结配对、功效依据和后验限制。已见的 HMB 与历史 S0-4 用于开发或历史审计。须取得 `FINAL_TEST_SEALED` manifest、完整无交集来源证明和访问审计，候选锁定后一次解封。失败、截断及退出不重写，重新研发需另立独立终评数据与授权。

保留下列物理挑战及完整分布。正式物理评分需要对应物理域、独立基座注册、合格设备时钟和遥测、实测 Servo 及外部计量。仿真可以按同名统计作对照，标注仿真域。

| 指标 | 最终挑战 | 主场景与单位 |
|---|---:|---|
| Static max-ten-tip P95 | ≤3 mm | 有效静态末窗，mapped 主列及 feasible 辅列。 |
| Dynamic max-ten-tip P50/P95/P99 | ≤2/5/10 mm | 原速完整轨迹、原始物理时间轴。 |
| Hard-motion max-ten-tip P95 | ≤10 mm | 预注册困难连续域。 |
| Pinch geometry P95 | ≤2 mm | 功能激活掩码，毫米向量误差，距离另报。 |
| Bimanual relative P95 | ≤3 mm | 冻结跨手相对向量，双腕相对 SE(3) 另报。 |
| Static fingertip speed RMS | ≤1 mm/s | 末窗实际反馈。 |
| Small-disturbance recovery | ≤300 ms | 批准幅度、触发与恢复窗；报告未恢复率及删失。 |
| Actor inference P99 | ≤5 ms | 目标平台 batch=1，含同步，分段基准。 |
| Real end-to-end latency | ≤50 ms | 原始传感采样至物理响应，候选 P95，完整分布、覆盖和测量不确定度。 |
| Dynamic/hard relative improvement | ≥20% | 动态及困难场景分别对预注册同条件对照；复合分位数与配对区间。 |

静态不可达界、计量噪声、动态带宽及测量延迟用于解释结果，任何阈值变更需新 DCR 和人工决定。正式对照至少考虑臂/手自由度、意图目标、奖励尺度、双手几何、历史、鲁棒性，必要时补充 PPO 与 SuperMimic、Jacobian 或传统名义控制消融。报告 transition 及计算开销，均使用相同评分器及独立物理运行现象作结论。

适用掩码来源须分别登记。M1 的 20 mm 阈值只用于冻结几何映射，训练 Reward 的 30 mm 候选只影响训练项权重。正式计分按 E2/E3 的冻结适用规则和对应目标层读取，评分器不得读取训练 dropout 或奖励权重作为资格。
