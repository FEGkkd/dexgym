# Isaac Lab 2.x archive

This directory preserves the prior asset configuration modules, scenes,
low-level validation helpers, historical environment/tool scripts, data contract,
and historical tests. They are
outside the DexGym 2.0 installed package and current pytest collection. The
PhysX-specific modules have not been migrated to or verified with Newton.

The former task implementations and wrappers were removed from the active
branch. They remain recoverable from Git history at commit `eeba754`:
Shadow Hand Pose/Reorientation, Allegro Hand Track/Repose, Wuji Hand
Reorientation, Wuji Arm-Hand scaffold, bimanual bottle, and bimanual pregrasp
CapTurn. Their prior registration is not active in DexGym 2.0.
